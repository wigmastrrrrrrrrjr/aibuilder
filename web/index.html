       Install the CLI
      
    
      
    
      
      
      Build aibuilder apps right from your terminal — on Linux, macOS, Windows and Android (Termux) — with the same account and credits as the web app.
      
      
      
        
       macOS · Linux · Android (Termux)
      
        
      curl -fsSL https://wigmastrrrrrrrrjr.github.io/aibuilder/install.sh | sh
          
        
      
      
      
      
      
        
       Windows (PowerShell)
      
        
      irm https://wigmastrrrrrrrrjr.github.io/aibuilder/install.ps1 | iex
          
        
      
      
      
      
      1
      Run the command above on any device.
      
      
      2
      Run aib login — sign in with your aibuilder account.
      
      
      3
      Run aib to start a terminal session. Prompts go to the same AI, and every generated file lands in a real folder on your machine.
      
      
      Building from source? cd tui && cargo build --release (Rust required).
